## قواعد استخدام المتغيرات

- لا تطلب من المستخدم إعادة معلومة موجودة هنا أو في مخرجات سابقة.
- لا تعتبر اسم منافس أو رابط تصميم مرجعاً معتمداً إلا إذا كان مذكوراً بوضوح.
- لا تفترض أن التقنية الحالية هي الاختيار الأفضل؛ قيّمها مقابل القيود والاحتياجات.
- وثّق أي تغيير في المتغيرات، واذكر سبب التغيير والمرحلة المتأثرة.
- لا تضع كلمات مرور أو API keys أو بيانات دخول في هذا الملف. استخدم مدير أسرار آمن.
