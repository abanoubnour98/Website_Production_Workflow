# Stage 02 — SEO Strategy & Architecture

**بالعربية:** استراتيجية SEO وهيكلة الموقع  
**رقم المرحلة:** 02 من 13

## 1. الهدف

تنفيذ مرحلة **SEO Strategy & Architecture** ضمن منهجية بناء الموقع، وتسليم مخرجات قابلة للمراجعة والاستخدام في المرحلة التالية.

## 2. المهارات المطلوبة (Skills)

SEO Audit, Keyword Research, Search Intent Analysis, SERP Analysis, Topical Mapping, Site Architecture, URL Planning, Internal Linking Strategy

## 3. يعتمد على (Previous Inputs)

Stage 01: project brief, audience research, competitor matrix, goals and constraints. Existing URLs, sitemap, Search Console and crawl data if available.

> قبل التشغيل، أرفق الملفات الفعلية للمراحل السابقة. لا تعتمد على افتراض أن الـAgent يتذكر محادثة أو يستطيع فتح ملفات غير مرفقة.

## 4. المهام المطلوبة

1. Audit the current website where one exists: crawlable URLs, indexability, titles, headings, canonicals, status codes, redirects, internal links and content coverage.
2. Research keyword themes and relevant search queries for each target market and language using available tools and SERP evidence.
3. Classify search intent and identify the best page type for each topic.
4. Cluster related terms by topic and intent; map one primary intent to one target page where appropriate.
5. Build the site hierarchy, categories, navigation, URL conventions, breadcrumbs and page inventory.
6. Create a contextual internal-linking plan connecting pillar pages, categories and supporting pages.
7. Identify cannibalization, duplication, orphan-page and content-gap risks; prioritize by relevance and business value.

## 5. المخرجات المطلوبة (Deliverables)

- Current-site SEO audit (or clearly scoped baseline if no site exists)
- Keyword research database with source/tool and date
- Keyword-to-URL map and search-intent map
- Topical clusters and content gap analysis
- Proposed sitemap and URL structure
- Navigation and breadcrumb plan
- Internal-linking matrix
- Prioritized SEO implementation backlog

## 6. معايير القبول (Acceptance Criteria)

- [ ] Every priority URL has a defined purpose, target intent and page type.
- [ ] Existing URLs are preserved or proposed changes have documented reasons and redirect needs.
- [ ] Keyword metrics are sourced or marked unavailable; no invented volumes or difficulty scores.
- [ ] Internal links are relevant and the proposed hierarchy avoids unnecessary duplication.
- [ ] Priority pages and unresolved SEO decisions are documented.

## 7. Tips & Best Practices

- Use actual SERPs to validate intent; keyword tools alone do not define the right page type.
- Do not create one thin page for every keyword variation.
- Keep existing valuable URLs unless there is a compelling, documented reason to change them.
- Treat language and country targeting carefully; define URL and hreflang conventions before publishing.
- Prioritize user usefulness and topical coverage over keyword density.
