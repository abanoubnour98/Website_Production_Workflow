# Website Production Workflow — دليل الاستخدام

حزمة منظمة لإدارة بناء موقع من البحث الأولي وحتى الإطلاق والتحسين المستمر.

## محتويات الحزمة

- `00_WORKFLOW_OVERVIEW.md` — جدول المراحل الـ13: المهارات، المدخلات، المخرجات، ومعيار الانتقال.
- `00_PROJECT_CONFIGURATION.md` — متغيرات المشروع التي تملؤها مرة واحدة.
- `00_MASTER_INSTRUCTIONS.md` — تعليمات مشتركة تُضاف إلى بداية كل Prompt.
- `STAGES/` — ملف مستقل لكل مرحلة، يحتوي على المهارات، الاعتماديات، خطوات التنفيذ، Prompt جاهز، المخرجات، ومعايير الجودة.
- `HANDOFF_TEMPLATE.md` — نموذج موحد لتسليم مخرجات كل مرحلة للمرحلة التالية.

## طريقة الاستخدام

1. افتح `00_PROJECT_CONFIGURATION.md` واملأ المعلومات المتاحة فقط. اترك غير المعروف فارغاً.
2. اقرأ `00_MASTER_INSTRUCTIONS.md` مرة واحدة، واستخدمه مع كل مرحلة.
3. ابدأ بالمرحلة 01 ثم اتبع ترتيب المراحل في `00_WORKFLOW_OVERVIEW.md`.
4. لكل مرحلة، انسخ قسم **READY-TO-USE PROMPT** من ملفها. ألحق به تعليمات `00_MASTER_INSTRUCTIONS.md` وبيانات المشروع.
5. زوّد الـAgent بمخرجات المراحل السابقة المشار إليها في خانة **Depends on / Previous Inputs**. لا تفترض أنه يستطيع الوصول إليها تلقائياً.
6. لا تنتقل إلى المرحلة التالية قبل اجتياز **Acceptance Criteria** وتعبئة `HANDOFF_TEMPLATE.md`.
7. يمكن تنفيذ المرحلتين 07 و08 بالتوازي بعد اعتماد المرحلة 06، بشرط الاتفاق على واجهات التكامل. ويمكن تنسيق 09 و10 بالتوازي بعد توفر بيئة قابلة للاختبار ومحتوى معتمد.

## قاعدة مهمة

هذه الحزمة هي منهجية عمل وقوالب Prompts، وليست إثباتاً أن البحث أو التطوير أو الاختبار قد تم بالفعل. يجب أن ينفذ الـAgent المهام ويقدم أدلة فعلية وملفات قابلة للمراجعة. لا تسمح له بادعاء اكتمال مهمة لم ينفذها.

## اللغة

- الشرح والتنظيم بالعربية.
- Prompts التنفيذ بالإنجليزية لتكون سهلة الاستخدام مع معظم أدوات وAgents الذكاء الاصطناعي.
- عند إنشاء موقع متعدد اللغات، يجب أن تكون كل لغة تجربة محتوى وتصميم كاملة، لا ترجمة حرفية فقط.
